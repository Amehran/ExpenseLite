- (constraint) Platform: Android Min SDK 26 / Target SDK 35; Kotlin 2.x only; no deprecated XML views, no LiveData in UI, no un-scoped coroutines
- (constraint) UI: Jetpack Compose + Material 3; Single Activity; enableEdgeToEdge() mandatory
- (constraint) Architecture: Clean Architecture + MVVM; strict UDF; immutable state streams; StateFlow collected via collectAsStateWithLifecycle()
- (constraint) DI: Hilt throughout; @HiltViewModel; interfaces required for all Repositories and DataSources to enable test-double injection
- (constraint) Persistence: Room via KSP for relational data; Preferences DataStore for settings
- (constraint) Navigation: Navigation Compose with type-safe @Serializable routes
- (constraint) File I/O: Storage Access Framework only; zero runtime permissions needed for export/import
- (constraint) Money storage: all amounts stored as Long in minor units (cents); never Double/Float; annual subscription divided by 12 for monthly projection only
- (constraint) Layer isolation: Room entities must never appear in UI composables; map to domain models at repository boundary
- (constraint) State contracts: every screen must define sealed interfaces for FeatureUiState, FeatureUiEvent, FeatureSideEffect
- (constraint) Dispatcher injection: Dispatchers.IO/Default never hardcoded; injected as @IoDispatcher CoroutineDispatcher via Hilt
- (constraint) Logging: zero android.util.Log; Timber only; debug logs stripped in release via R8/ProGuard
- (constraint) Build gate: build must fail on any ktlintCheck or detekt error (non-ignored)
- (constraint) Validation: amountCents > 0; transaction date no more than 1 calendar year in the future; custom category names unique case-insensitive, cannot duplicate system names; system categories immutable
- (constraint) Observability: Firebase Crashlytics for non-fatal domain errors in release; Timber initialized in Application class
- (decision) Non-goals: bank sync/Plaid, multi-currency, user auth, cloud sync, Firebase Auth, Firebase Firestore — all explicitly out of scope for MVP
