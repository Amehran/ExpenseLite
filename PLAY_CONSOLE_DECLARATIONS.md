# Play Console Declarations for ExpenseLite

This document outlines the standard Google Play Console Questionnaire declarations for ExpenseLite.

## 1. Data Safety Questionnaire Answers
- **Does your app collect or share any user data?** $\rightarrow$ **No**.
- **Data Collection:** No user data (financial data, personal info, identifiers, app info, location, photos) is collected or transmitted off the device.
- **Data Security:** Data stored locally on device.
- **Data Deletion:** Users can delete all data at any time by wiping app storage or uninstalling the application.

## 2. App Content Declarations
- **Financial Features:** Financial Management / Expense Tracker (Offline-only, no banking API integration).
- **Target Audience:** General Audience (18+ / All Ages).
- **Ads:** No ads present.
- **Background Location / Sensitive Permissions:** None.

## 3. Store Listing & Video Requirements
- **YouTube Video URL (Optional / XR):** If adding a video link:
  - Must be **Public** or **Unlisted** YouTube URL.
  - Ads / Monetization MUST be turned OFF.
  - Must NOT be age-restricted.
  - Paste your YouTube video link into Google Play Console under **Store Presence -> Main Store Listing -> Preview Video / Non-spatial XR Video**.
